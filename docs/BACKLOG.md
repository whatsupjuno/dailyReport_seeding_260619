# 백로그 (미구현 · 요청 기록)

> 아직 구현하지 않음. 우선순위/일정은 추후 결정.

## 신규 요청 (2026-06-19)
1. **업무별 댓글** — task 단위 코멘트/스레드. (현재: 보고서 단위 일일 코멘트 + task `hold_reason`(지연 사유)만 존재)
   - 모델 후보: `task_comments(task_id, author_user_id, body, created_at)`. 작성자/검수자 모두 작성 가능 여부 결정 필요.
2. **휴직, 기타 + 사유 처리** — 휴가 유형에 **휴직** 추가, **기타·휴직 선택 시 사유 필수 입력**.
   - 현재: `vacation_type` enum(연차/반차/병가/공가/기타) + `vacation_comment` 존재하나 사유 강제 없음. enum에 `휴직` 추가 + 기타/휴직일 때 comment 필수 검증.
3. **업무별 반려** — 검수자가 **특정 업무(task) 단위로 반려**.
   - 현재: 시간대 지목 반려(전체/오전/오후/야간)만. task 단위 반려 상태 + 사유 + 직원 재작성 흐름 설계 필요.
4. **오늘 할 일 일괄 작성 + 완료 시점 기준 오전/오후 자동 분류** — 아침에 하루 업무를 한 번에 작성, 각 업무의 **완료 시각**으로 오전/오후 자동 구분.
   - 현재: 계획→오전마감→오후계획→오후마감의 순차 시간대 흐름. 이 항목은 작성 모델(섹션 고정 배정) 자체를 바꾸는 변경 — task에 완료시각 기록 + 시간대 동적 분류 설계 필요. 영향 범위 큼.

## 기존 보류 (요청대로 미진행)
- 강제 마감(시간대 일괄), 개인 프로필 변경(이름/이메일)
- 야간 종료 예상시각 정밀 입력 + 미작성 30분후 5분단위 리마인더
- 정성지표(효율성·연속성·연관성) 자동/AI 산출 (디자인상 v2)
- 자동 OTP 발급·메일 인증 (현재 고정 4자리 코드 유지)
- (제안) 발송 직후 결과 요약을 관리자에게 알리는 헬스체크
